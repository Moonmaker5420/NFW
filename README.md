# NFW — Next Firewall

An OPNsense-like firewall for any Debian/Ubuntu server.

## Install

    curl -sSL https://raw.githubusercontent.com/Moonmaker5420/NFW/main/install.sh | sudo bash

See `install.sh` for details, or run with `NFW_SOURCE=/path/to/local/tree sudo bash install.sh`
for local development.

## Uninstall

    sudo bash /opt/nfw/uninstall.sh
